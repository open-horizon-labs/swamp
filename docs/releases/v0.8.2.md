# Swamp 0.8.2

This release makes it easier to compare project growth and review what to remove. Less text in the way; the supporting facts stay available.

- **Know what “Change” means.** Project tables show the period: `Change 7d`. Press `w` to choose another. Swamp recalculates from stored history without scanning your projects. Shorter available history appears as `Change ~5d`; clearing the filter keeps your chosen period. This also fixes a bug where changing the filter’s period changed the label without recalculating the numbers.
- **Read a shorter Trash review.** Restore cost, sourced last use and consequential exceptions lead the review. Press `l` for every path and the full supporting facts. Large selections have a scrollable inventory instead of requiring a taller terminal. Removed model manifests disappear immediately from current views; shared layers remain counted.
- **Keep your place.** Inspect directories preserves the selection and scroll position. Sorting keeps the same item selected, and returning to a view restores its position. Tables give names and recovery costs more room, hide empty columns and retain labels for unknown measurements.
- **Follow an observation.** Progress uses one elapsed clock and the current work stage, instead of byte counters that restart for each root. Busy-observer messages show a readable start time and elapsed age. Dates, durations, counts and sizes use coarse human-readable formatting; JSON precision is unchanged.
- **Prepare Cargo cleanup faster.** Swamp checks payload metadata instead of reading and hashing compiled binaries. One local 499-item selection took 0.27 seconds to prepare, down from 15.7 seconds. That is a measured example, not a timing guarantee.

The release includes macOS arm64 and Linux x86_64 archives, each with the CLI/TUI and agent skill. Moving files to Trash frees space when those files are emptied from Trash.

Update with `brew upgrade swamp`, or download the archive and checksum from the release assets. Reopen an existing TUI session to use the new controls.
